**시의성 있는 해외송금 관련 블로그 콘텐츠**를 자동 생산한다.

## 2. 시장 분석 데이터 소스 (무료)

### 2-1. 환율 데이터 (open.er-api.com)
- 8개 통화의 현재 환율
- 전일 대비 변동률 (fee-data.json 이전 값과 비교)
- 주간/월간 추세 방향

### 2-2. 뉴스/이벤트 시그널
- **환율 급변 감지**: 전일 대비 ±1% 이상 변동 통화
- **시즌 이벤트**: 유학 시즌(1-3월, 8-9월), 해외여행 성수기(7-8월, 12월), 연말정산(1월)
- **정기 이벤트**: 한은 금통위(연 8회), FOMC(연 8회), BOJ 회의, ECB 회의
- **한국 공휴일 연휴**: 설날, 추석 전후 송금 수요 증가

### 2-3. 컨텍스트 데이터
- 5년 히스토리 기반 현재 환율 백분위 (상위/하위 몇 %인지)
- 최근 30일 추세 (상승/하락/횡보)
- 각 서비스별 최신 프로모션 정보 (fee-data.json에서 추출)

## 3. 주제 선정 정책

### 3-1. 우선순위 (높은 순)

| 우선순위 | 트리거 조건 | 주제 유형 | 예시 |
|----------|------------|-----------|------|
| P0 긴급 | 환율 ±2% 이상 급변 | 긴급 분석 | "원달러 2% 급등, 지금 송금해야 할까?" |
| P1 시의성 | 환율 ±1% 변동 | 시장 분석 | "엔화 약세 지속, 일본 송금 적기 분석" |
| P2 시즌 | 시즌 이벤트 해당일 | 시즌 가이드 | "9월 유학 송금 시즌, 서비스별 비교" |
| P3 트렌드 | 5년 최저/최고 근접 | 역사적 분석 | "유로 5년 최고치 근접, 환율 전망" |
| P4 정기 | 위 조건 미해당 | 교육/팁 | "해외송금 수수료 구조 완벽 이해" |

### 3-2. 중복 방지
- Notion DB에서 최근 30일 발행 제목 조회
- 동일 통화 + 동일 카테고리 조합은 7일 내 재사용 금지
- slug 중복 시 날짜 접미사 추가

### 3-3. 카테고리 배분 (주간 기준)
- 시장분석/뉴스: 3-4회
- 가이드/비교: 1-2회
- 팁/초보자: 1-2회

## 4. 콘텐츠 품질 정책

### 4-1. 데이터 기반 작성
- 모든 포스트에 **당일 실시간 환율** 수치 포함
- 서비스별 수수료/스프레드 **실제 데이터** 인용
- "약 ~원" 같은 모호한 표현 금지, 구체적 숫자 사용
- 5년 평균 대비 현재 위치 백분위 명시

### 4-2. 구조 요구사항
- 본문 **3,000-4,000자** (한글 기준)
- H2 섹션 6-8개
- 비교표 또는 숫자 리스트 최소 1개 포함
- FAQ 섹션 3-5개 질문
- CTA: cross-border-remittance-lookup.web.app 자연스럽게 1-2회 언급

### 4-3. SEO 요구사항
- 제목 30-50자, | 구분자 포함
- 메타 설명 120-155자
- 핵심 키워드 본문 내 5-8회 자연 분포
- 날짜 포함 (2026년 6월, 이번 주 등)

### 4-4. 품질 검증 기준
- 최소 글자수: 2,000자 (미달 시 보충 요청)
- 목표 글자수: 3,000-4,000자
- H2 섹션 수: 최소 5개
- 숫자/데이터 포함: 최소 10개 이상의 구체적 수치
- 할루시네이션 방지: 프롬프트에 실제 데이터만 전달

## 5. 프롬프트 전략

### 5-1. 시스템 프롬프트
```
당신은 한국의 해외송금 전문 애널리스트이자 블로그 작가입니다.
오늘의 실시간 시장 데이터를 기반으로 정확하고 유용한 콘텐츠를 작성합니다.
제공된 데이터만 사용하고, 추측이나 허위 정보를 포함하지 마세요.
```

### 5-2. 데이터 주입 형식
```
[오늘의 시장 데이터]
- 날짜: 2026-06-17 (화)
- USD/KRW: 1,474원 (전일 대비 +0.3%, 5년 평균 대비 +12%)
- JPY/KRW: 938원 (전일 대비 -0.5%, 5년 최저 근접)
- 최저비용 서비스: Wise (수수료 0원, 스프레드 0.45%)
- 시즌: 여름 해외여행 성수기
```

### 5-3. 2단계 생성
1. **분석 단계**: 시장 데이터를 보고 오늘의 핵심 인사이트 3개 도출
2. **작성 단계**: 인사이트 기반으로 본문 작성 (데이터 수치 필수 포함)
